## [1.0.0] - 2026-01-20

### 🎉 Initial Release

#### Core Features
- ✅ **Chat Panel** — Unlimited conversation with brainstorm/code mode toggle
- ✅ **Preview Panel** — Live rendering with Web/Android/Windows device frames
- ✅ **Mind Panel** — Persistent memory with xerj graph integration
- ✅ **Terminal Panel** — Sandboxed command execution (with backend)
- ✅ **Project Manager** — Create and manage multiple projects
- ✅ **Template Library** — 15+ pre-built app templates
- ✅ **Auth System** — Google login + guest mode (no account required)

#### Advanced Tools
- ✅ **Build Pipeline** — 5-stage app generation (Design → Generate → Test → Build → Deliver)
- ✅ **RAM Graph** — Working memory visualization with loop detection
- ✅ **Voice Conversation** — KittenTTS + Whistle STT integration
- ✅ **Autocorrect** — Self-designed error detection with configurable rules
- ✅ **CRUCIBLE Vetting** — 6-step adversarial validation system
- ✅ **Settings Panel** — Hardware detection, AI model, framework, backend selection

#### Code Generation
- ✅ **Real HTML Generation** — Landing pages, todo apps, login forms, portfolios, dashboards
- ✅ **Live Preview** — Sandboxed iframe with srcdoc rendering
- ✅ **Download/Copy** — Export generated code
- ✅ **Device Frames** — Android phone, Windows desktop, Web browser

#### Platform Features
- ✅ **100% Free & Unlimited** — No API costs, no usage caps
- ✅ **Local-First** — Ollama, Needle, LM Studio support
- ✅ **Dual Framework** — React Native + Flutter (auto-select)
- ✅ **Free Backends** — Firebase, Supabase, Appwrite, offline
- ✅ **Smart Publishing** — Personal (debug) vs Google Play (compliant)
- ✅ **Voice Interface** — 47 voices, 7 languages, wake word detection
- ✅ **Auto-Translator** — Mirror user's language automatically
- ✅ **Hardware Adaptive** — Detects specs, adjusts performance
- ✅ **Repo Import** — "Adopt any repo as mind" for instructions

#### Documentation
- ✅ **README.md** — Project overview and quick start
- ✅ **SETUP_GUIDE.md** — Complete setup instructions with CLI bridge
- ✅ **QUICK_START.md** — 60-second quick reference
- ✅ **CONTRIBUTING.md** — Developer guidelines
- ✅ **CHANGELOG.md** — This file

#### Setup Scripts
- ✅ **setup.sh** — Mac/Linux auto-setup
- ✅ **setup.bat** — Windows auto-setup
- ✅ **VSCode Config** — Extensions, settings, launch, tasks
