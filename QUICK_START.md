# ⚡ Quick Start Guide

Get up and running in **60 seconds**.

---

## 🚀 One Command Setup

### Mac/Linux
```bash
chmod +x setup.sh && ./setup.sh
```

### Windows
```cmd
setup.bat
```

**That's it!** The script will:
- ✅ Install all dependencies
- ✅ Set up VSCode with extensions
- ✅ Start the dev server
- ✅ Open your browser

---

## 📱 What You Get

Once running, you can:

1. **Chat** — Describe what you want to build
2. **Preview** — See it rendered live
3. **Mind** — Save memories and preferences
4. **Terminal** — Execute real commands (with backend)
5. **Projects** — Manage multiple apps
6. **Templates** — Start from pre-built templates

---

## 🎯 Try It Now

1. Click **"Continue Without Login"**
2. In chat, type: **"Build me a todo app"**
3. Switch to **Preview** panel
4. Click **Run**
5. You'll see a working todo app!

---

## 🔗 Enable CLI Access (Optional)

To run real commands in the terminal:

```bash
# Terminal 1 - Start backend
node server/server.js

# Terminal 2 - Start frontend
npm run dev
```

Now your terminal can execute `npm`, `git`, `gradle`, etc.
